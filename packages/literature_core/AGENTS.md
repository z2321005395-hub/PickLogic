# Literature Core Rules

- Never upload a PDF. DOI extraction and metadata lookup send only identifiers/metadata.
- Renaming is preview-only until a confirmed `OperationPlan` executes.
- Translation is off by default. It may receive only text from a scope the user explicitly requests (selection, current page, or document); never upload the PDF binary.
- PDF engine additions require license, binary, packaging, quality, and size audits.
- BibTeX/RIS are interfaces only in v0.1 unless explicitly promoted.
