# Roadmap

## M0 — Bootstrap

- Monorepo contracts, documentation, safety policy, synthetic fixtures, three launchable shells, tests, CI, dependency and brand audits.

## M1 — Three-target vertical slice

- Desktop Standard: synthetic scan -> category -> search -> split view -> preview -> Insight.
- Desktop Pro: synthetic PDF -> literature record -> reader -> metadata -> Insight -> System Insight test view.
- Mobile: MediaStore/SAF -> screenshots/photos/files/storage -> Insight, with a usable first screen before complete indexing.

## M2 — v0.1.0-alpha

- SQLite incremental index, SHA-256 duplicates, bounded thumbnails, safe operation planner, platform bridges, three installable artifacts, size/privacy reports.
- Reference-machine and nubia Z70 read-only validation after explicit authorization.

## M3 — User testing

- Maintainer installation and first-use validation; accessibility, performance, permissions, recovery, and copy refinements.

## M4 — v0.1.0-beta

- Compatibility fixes, stable migrations, improved diagnostics, packaging and upgrade validation.

## M5 — First public stable release

- Final license/copyright, trademark review, public repository approval, signed artifacts, reproducible release gate, documentation and truthful release notes.

## Later, not v0.1

- Research project workspace, figure manager, data lineage, research log, citation exports/integrations, full-text literature search, page-evidenced Q&A.
- Deeper system/software relationship graphs, evidence-based residue analysis, startup/service/task explanations, restore/hibernation/pagefile education.
- Full background OCR, screenshot full-text search, perceptual grouping, lightweight expiring-content categories, user preference learning.
- Advanced PDF editing, OCR, rearrangement, and conversion only after license, size, quality, privacy, and maintenance audits.
