# PickLogic v0.1.0-alpha — Draft Release Notes

Private maintainer-validation draft. Not published.

## Included

- PickLogic Desktop: synthetic-safe scan/index/search/classification, split preview, exact duplicates, operation preview, and Insight.
- PickLogic Pro: the same desktop shell plus bounded literature metadata, rename preview, reading state, virtual research buckets, and read-only System Insight.
- PickLogic Mobile: MediaStore/SAF shell, Files/Screenshots/Photos/Storage, bounded thumbnails, timeline screenshot groups, review queue, and Insight.
- Shared local models, SQLite index, deterministic rules, SHA-256, bounded caches, bilingual architecture, and Developer Safe Mode.

## Safety

No real user file or media item was moved, renamed, deleted, or uploaded during development. Public conversion, signing, and publishing remain disabled.
