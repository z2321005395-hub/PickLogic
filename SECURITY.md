# Security Policy

## Supported versions

PickLogic has no released version yet. Security fixes apply to the active development branch until a versioned support policy is published.

## Reporting

Do not open a public issue containing exploit details, private paths, logs, tokens, or user data. Once the private GitHub repository exists, use a private GitHub Security Advisory. If that channel is unavailable, contact the maintainer privately and provide only the minimum reproducible details.

Never include real personal files. Use synthetic fixtures and redact locators, identifiers, and device serials.

## Response expectations

The maintainer will acknowledge a valid private report, assess affected targets, reproduce safely, prepare tests and a fix, and coordinate disclosure after a patched artifact exists. Exact service-level commitments will be added before the first public release.
