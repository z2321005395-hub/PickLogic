# Project Context

PickLogic / 拾理 is a local-first file understanding and organization product with three release targets in one Flutter/Dart monorepo:

- PickLogic Desktop: Windows Standard.
- PickLogic Pro: the same desktop app with Literature, Research, and System Insight capabilities enabled.
- PickLogic Mobile: Android, focused first on screenshots, media, files, and storage insight.
